## How to Contribute

1. **Quick note:** Add an entry to `INBOX.md` using the template there. A rough entry beats none.
2. **Direct edit:** Edit any document directly. Follow the standards in the handoff (every rule has a reason, be concrete, label confidence). Your edits will be kept and brought up to standard during the next refresh.
3. **Decision record:** Add to `01_ARCHITECTURE.md` using the decision record format.

See the contribution routing table in `handoff.md` for where each type of contribution belongs.
